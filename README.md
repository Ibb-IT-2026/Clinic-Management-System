# نظام إدارة العيادات الطبية (Clinic Management System)

مشروع تخرج مققر هندسة البرمجيات - 2026.

## 🎯 أهداف النظام

- تسهيل عملية حجز وإدارة المواعيد الطبية للمرضى.
- أرشفة السجلات الطبية والتشخيصات بشكل إلكتروني آمن.
- إدارة الحسابات، المدفوعات، وتوليد التقارير المالية والإحصائية للعيادة.
- توفير واجهة مستخدم مرنة تدعم الوضع الداكن (Dark Mode) والتجاوب مع مختلف الشاشات.

## 👥 فريق العمل (Team Members)

- **العضو الأول:** مطور تصميم الواجهات والهوية البصرية (UI/UX & Styling).
- **العضو الثاني:** مطور وحدة المرضى والسجلات الطبية (Patients & Records).
- **أبو جود (العضو الثالث):** مدير المشروع، مطور وحدة المواعيد والمدفوعات، وإدارة المستودع (Project Manager, Appointments, Finance & DevOps).

## 🛠️ تقنيات المشروع

- HTML5, CSS3, JavaScript (Vanilla)
- Git & GitHub لإدارة الإصدارات
